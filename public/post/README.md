# Assets fixos do template SM-Post

Este template espera dois arquivos aqui (exportados do Figma, página
"Test_SM-Post", frame "Instagram post - 1"):

1. `logo-fg.svg` — nó 271:9 ("[FG] Logo / White")
   No Figma: selecione a camada → botão direito → "Copy as" → SVG,
   ou use o painel Export (canto inferior direito) com formato SVG.

2. `logo-secondary.svg` — nó 271:56 ("Group 1", o wordmark de 22 paths)
   Mesmo processo de export.

Sem esses dois arquivos, o post ainda é gerado normalmente — só que
sem os logos (o canvas ignora silenciosamente uma imagem que não
carrega). Assim que você exportar e colocar os SVGs aqui, eles
aparecem automaticamente nas posições fixas (88,88) e (882,99).
